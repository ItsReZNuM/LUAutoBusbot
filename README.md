# ربات تلگرام رزرو خودکار سرویس دانشگاه (LUAutoBusbot)

ربات تلگرام پیشرفته، چندکاربره و خودکار برای رزرو، استعلام و مدیریت سرویس‌های اتوبوس دانشگاه لرستان از طریق سامانه ترابری وانابوم (رانا).

---

## 🌟 ویژگی‌ها و قابلیت‌های کلیدی

1. **چندکاربره واقعی (Multi-User)**:
   - هر کاربر با شناسه عددی تلگرام (`telegram_id`) خود تفکیک می‌شود.
   - ورود مستقیم درون تلگرام با شماره موبایل و کد پیامک یکبار مصرف (OTP).
   - حفظ و نگهداری امن سشن، نام کاربر و توکن‌های CSRF در دیتابیس SQLite.

2. **سیستم علاقه‌مندی‌ها (Favorites)**:
   - امکان ذخیره ایستگاه‌های پرکاربرد برای مسیرهای رفت و برگشت.
   - دسترسی فوری به ایستگاه‌های منتخب بدون نیاز به جستجو در لیست طولانی ایستگاه‌ها.
   - نمایش دقیق مسیر در کنار نام ایستگاه جهت جلوگیری از رزرو اشتباه (مثلاً تفکیک ایستگاه «مصلی به کمالوند» از مسیرهای دیگر).

3. **فرآیند رزرو مرحله‌به‌مرحله و هوشمند (Interactive Wizard)**:
   - دکمه‌های برگشت (`🔙 بازگشت`) در تمام مراحل رزرو و منوها.
   - انتخاب روزهای فعال سرویس‌دهی.
   - انتخاب ایستگاه با فیلتر هوشمند و تمیزسازی کدهای HTML.
   - دریافت آنی ساعت‌های موجود، مبلغ، ظرفیت خالی و نوع سرویس با دکمه‌های شیشه‌ای.
   - تایید نهایی رزرو به همراه دکمه لغو مستقیم (`❌ لغو همین رزرو`).

4. **سیستم زمان‌بندی و رزرو خودکار (Autonomous Scheduler)**:
   - فعال‌سازی رزرو خودکار برای هر کاربر با ساعت هدف دلخواه (مثلاً ساعت `00:00` یا `21:00`).
   - انتخاب روزهای هفته و ایستگاه‌های رفت و برگشت پیش‌فرض.
   - اجرای دوره‌ای و تلاش خودکار به محض باز شدن پلن روز بعد در سامانه.
   - ارسال اعلان تلگرامی با جزئیات کامل و کلید لغو اضطراری.

5. **مدیریت و لغو سفرها (Active Trips)**:
   - استعلام تمام رزروهای فعال با دستور `/trips`.
   - امکان لغو آنی هر سفر با دکمه شیشه‌ای لغو.

---

## 📋 لیست دستورات ربات (Slash Commands)

- `/start` : شروع کار با ربات، ثبت اطلاعات و نمایش منوی اصلی
- `/help` : راهنمای کامل استفاده از ربات و دستورات
- `/reserve` : شروع فرآیند رزرو دستی مرحله‌به‌مرحله
- `/trips` : مشاهده لیست سرویس‌های رزرو شده و لغو آن‌ها
- `/favorites` : مدیریت و مشاهده ایستگاه‌های نشان‌شده (علاقه‌مندی‌ها)
- `/settings` : تنظیمات رزرو خودکار (ساعت اجرا، روزها، ایستگاه‌ها)
- `/status` : وضعیت لاگین، سشن و اتصال به سامانه وانابوم
- `/login` : ورود با شماره موبایل و کد تایید پیامکی (OTP)
- `/logout` : خروج از حساب کاربری وانابوم در ربات

## 🚀 راهنمای نصب و راه‌اندازی روی لینوکس (VPS / سرور)

### ۱. پیش‌نیازها
```bash
sudo apt update
sudo apt install -y python3 python3-pip python3-venv git
```

### ۲. کلون کردن مخزن
```bash
cd /opt
sudo git clone https://github.com/ItsReZNuM/LUAutoBusbot.git Autobus
cd Autobus
sudo chown -R $USER:$USER /opt/Autobus
```

### ۳. راه‌اندازی سریع با اسکریپت
```bash
chmod +x run_bot.sh
./run_bot.sh
```

### ۴. متغیرهای محیطی اختیاری (در صورت لزوم)
اگر سرور شما در خارج از کشور قرار دارد و سامانه دانشگاه روی اینترنت بین‌الملل مسدود است، یا برای دسترسی به تلگرام در ایران نیاز به پروکسی دارید:
```bash
export TELEGRAM_BOT_TOKEN="YOUR_BOT_TOKEN"
export TELEGRAM_ADMIN_CHAT_ID="YOUR_CHAT_ID"
# پروکسی تلگرام (در صورت نیاز):
# export TELEGRAM_PROXY="socks5://127.0.0.1:10808"
# پروکسی دسترسی به سایت دانشگاه در صورت خارج بودن سرور از ایران:
# export IRAN_PROXY="http://user:pass@iran_proxy_ip:port"
```

### ۵. راه‌اندازی به صورت سرویس دائمی سیستم‌عامل (Systemd Service)
برای فعال نگه‌داشتن همیشگی ربات پس از بستن ترمینال و ری‌استارت سرور:
```bash
sudo cp autobus.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable autobus
sudo systemctl start autobus

# بررسی وضعیت سرویس:
sudo systemctl status autobus

# مشاهده لاگ‌های زنده:
journalctl -u autobus -f
```
