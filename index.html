🤖 روش ۲: اجرای مستقیم روی خود گوشی اندروید (با Termux - بدون نیاز به لپ‌تاپ!)

۱۰۰٪ رایگان و مستقل

می‌توانید برنامه رایگان Termux را روی گوشی نصب کنید و این سامانه را مستقیماً داخل خود گوشی اجرا کنید تا همیشه با سیم‌کارت ایران بدون فیلترشکن وصل شود:

  1. نصب Termux از سایت F-Droid یا GitHub.
  2. اجرای دستور: pkg update && pkg install python git -y
  3. کلون ریپازیتوری یا کپی پوشه پروژه روی حافظه گوشی.
  4. نصب پیش‌نیازها: pip install -r requirements.txt
  5. اجرا: python web_server.py
  6. باز کردن آدرس http://127.0.0.1:8000 در کروم گوشی!
